# NTX

Lightweight Windows cleaner built with PowerShell.

### Run

```powershell
irm https://raw.githubusercontent.com/kevinxsec/NTX/main/ntx.ps1 | iex
```

### Manual Usage

```powershell
git clone https://github.com/kevinxsec/NTX.git
cd NTX
.\ntx.ps1
```

### Requirements

- Windows 10 / 11
- PowerShell 5.1+
- No external dependencies
